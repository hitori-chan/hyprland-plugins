What v3 is checking

The selected baseline keeps the source renderer's information hierarchy while making the island boundary explicit. One control board exposes the geometry, palette, state, and interaction comparisons without splitting the preview controls across separate panels.

Island fit

Default is 360px wide, flush to the stage edge, and 30px below the top. The controls test whether that geometry survives narrow outputs.

Source spacing

Rows use 10px content insets and 3px joins. Compact and comfortable options change only row density, so card anatomy and app identity remain comparable.

Action hierarchy

Body click opens the notification, while a 500ms hold reveals snooze, mute, priority, and dismiss. No chevron or kebab competes with those gestures.

Reply ownership

The Reply chip is the only center surface that owns keyboard input. Enter sends, Escape returns to the row, and the preview keeps the action inside the notification.

Footer and badge

DND stays a compact 34px control; Clear all remains the source text action. The conversation badge is an opaque 20px disc with a 16px app mark and 2px rim.

OSD separation

Volume, brightness, touchpad, and battery use stable semantic marks. Below-island is the source placement; aligned and detached are explicit comparison options.
